Installation guide

Install Lumen and GSPICE

These steps are written for circuit design engineers who want to get from a clean machine to schematic capture and simulation. Pick your operating system and follow the numbered flow.

Windows
  1. Recommended prerequisites: Git for Windows, CMake, Python 3, and Visual Studio Build Tools with the C++ workload.
  2. Download install-windows.ps1 using the button on the right.
  3. Open PowerShell in the download folder.
  4. Run the installer command below. It prints [OK] or [MISSING] for each prerequisite and asks before installing anything missing with winget.
  5. After prerequisites pass, it clones Lumen and GSPICE, builds GSPICE, and prepares the Lumen Python environment.
  6. When it finishes, start Lumen with the launch command shown below.
  7. After Lumen opens, configure GSPICE and the PDK using the setup steps below.
Run installer
powershell -ExecutionPolicy Bypass -File .\install-windows.ps1
Launch Lumen
cd "$HOME\lumen-gspice\Lumen_Circuit_Studio"
$env:QT_QPA_PLATFORM = "windows"
.\.venv\Scripts\pythonw.exe -m lumen
Download script
macOS
  1. Recommended prerequisites: Xcode Command Line Tools, CMake, Git, and Python 3.
  2. Download install-macos.sh using the button on the right.
  3. Open Terminal in the download folder.
  4. Run the two commands below. The script prints [OK] or [MISSING] for each prerequisite and asks before installing anything missing with Xcode tools/Homebrew.
  5. After prerequisites pass, it clones both projects, builds GSPICE, and creates Lumen's Python environment.
  6. After Lumen opens, configure GSPICE and the PDK using the setup steps below.

Add GSPICE in Simulator Manager
  1. In Lumen, open Tools > Simulator Manager....
  2. Select the GSPICE row.
  3. Click Locate Executable....
  4. Browse to the GSPICE executable built by the installer.
  5. Confirm the status changes to Found.
Default GSPICE paths
Windows:
$HOME\lumen-gspice\GSPICE\build-vs2022\Release\gspice.exe

macOS:
$HOME/lumen-gspice/GSPICE/build/gspice

Linux:
$HOME/lumen-gspice/GSPICE/build/gspice

If Windows was built from a Developer PowerShell instead, also check GSPICE\build\Release\gspice.exe.

If CMake reports nmake is missing, download the latest Windows installer from this page and rerun it. The updated script uses a Visual Studio build folder named build-vs2022.

Install and activate a PDK
  1. In Lumen, open Tools > PDK Manager....
  2. Choose the target PDK from the Active PDK dropdown.
  3. Click Install. Wait for the installed confirmation.
  4. Click Set Active so new schematics use that PDK.
  5. Open the Devices, Layers, and Corners tabs to confirm the PDK content loaded.

For the bundled open flow, select the included PDK, install it, then set it active before creating the first library or schematic.

First simulation check

After adding GSPICE and activating a PDK, create or open a small RC schematic, open the simulation environment, choose a transient analysis, run GSPICE, and open the RAW or CSV result in SigView. That verifies the schematic-to-simulator-to-waveform path.

Manual build commands 
git clone https://github.com/hegdeshreesha/GSPICE.git
cd GSPICE
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
git clone https://github.com/hegdeshreesha/Lumen_Circuit_Studio.git
cd Lumen_Circuit_Studio
python -m venv .venv
# Windows: .\.venv\Scripts\Activate.ps1
# macOS/Linux: . .venv/bin/activate
python -m pip install -r requirements.txt
python scripts\verify_environment.py
# Windows: $env:QT_QPA_PLATFORM = "windows"
# macOS: export QT_QPA_PLATFORM=cocoa
# Linux: export QT_QPA_PLATFORM=xcb
# Windows GUI launch: .\.venv\Scripts\pythonw.exe -m lumen
python -m lumen
