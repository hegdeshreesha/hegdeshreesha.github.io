Why Lumen EDA?

Two Engines, One Vision

GSPICE delivers industrial-grade simulation speed, while Lumen Circuit Studio provides a complete schematic-to-layout EDA experience.

Under the Hood

Technology Stack

Built with modern C++, scientific computing libraries, and a Python-native GUI framework.

C++17 Core

Modern C++ with RAII, templates, and policy-based design for extensible device modeling.

OpenMP Parallel

Multi-threaded device evaluation and matrix stamping scaling up to 16 threads.

SuiteSparse/KLU

Industry gold-standard sparse matrix solver for large circuit simulations.

OSDI / Verilog-A

Native Open Simulation Device Interface host for BSIM4, PSP, HICUM models.

Python GUI

Lumen Circuit Studio built in Python with PyQt6 for a responsive, cross-platform UX.

Harmonic Balance

Advanced RF analysis with PSS, HB, PAC, PNOISE, and envelope following.

KLayout Integration

IHP SG13G2 PDK with PCells, DRC/LVS command flow, and GDS export.

Monte Carlo

Deterministic Gaussian/uniform sampling with optional Latin-hypercube support.

Get Started

Download & Quick Start

Clone the repo, build with CMake, and run your first simulation in minutes.

GSPICE

git clone https://github.com/hegdeshreesha/GSPICE.git
cmake -S . -B build && cmake --build build --config Release
gspice circuit.sp --threads 8
View Releases

Lumen Circuit Studio

git clone https://github.com/hegdeshreesha/Lumen_Circuit_Studio.git
.\scripts\bootstrap_dev.ps1
python -m lumen
